KANPANについて

天井高2.7m、床面積75㎡。コンクリートの質感が残る、無機質で開放感のある空間です。展示、ポップアップストア、音楽イベント、撮影、パーティーなど、さまざまな用途でご利用いただけます。

  • 立地：梅田スカイビルから徒歩1分。大阪駅・梅田エリアから歩いて来られます。
  • 広さ：シンプルで使いやすい75㎡。最大100名程度までご利用いただけます。
  • 1階は醸造所兼パブ：メディアでも取り上げられた「KOFUNE SAKE BREWERY」が1階にあります。1階のパブで購入した日本酒を2階に持ち込んで、イベントを行うことも可能です。ケータリングのオプションもあります（フードオプション）。
